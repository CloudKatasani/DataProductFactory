# DataProductFactory
**Data Product Factory (DPF)** is an enterprise-grade, **locally hosted** web application that takes a team through the complete lifecycle of designing, building, certifying, and operating a **data product** — with a **human review-and-approval gate at every stage**.

The application lives in the [`ClaudeCode/`](./ClaudeCode) folder.

- **Run it locally:** see [`ClaudeCode/RUNNING.md`](./ClaudeCode/RUNNING.md) for step-by-step setup (Node + pnpm + SQLite, `http://localhost:3000`).
- **Project overview & conventions:** [`ClaudeCode/README.md`](./ClaudeCode/README.md) and [`ClaudeCode/CLAUDE.md`](./ClaudeCode/CLAUDE.md).
